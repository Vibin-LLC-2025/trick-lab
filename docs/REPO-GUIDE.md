# Repo guide

A plain-language map of the repo: what each folder is for and where to look when you want to change something.

## The big picture

Trick Lab is a web page. It has two halves:

- **The page around the 3D view:** the buttons, sliders, results, objectives and event log. This is ordinary React (`src/ui/`).
- **The 3D view in the middle:** the pad and the skateboard, drawn with three.js through React Three Fiber (`src/scene/`).

Underneath both sit **the physics** (`src/sim/`), which works out how the board flies and which trick happened, and **the store** (`src/store/`), the app's single shared memory that both halves read from.

When you press Pop: the UI calls a store action, the store asks the physics for the flight, the 3D view animates it, and when the board lands the store records the result, which the UI then shows.

## Top level

| File or folder | What it is |
| --- | --- |
| `README.md` | The front page: what the app is, how to run it, screenshots |
| `CLAUDE.md` | Rules for AI agents working in this repo (also a good summary of the conventions) |
| `package.json` | The project's dependencies and its commands (`npm run dev`, `build`, `verify` and others) |
| `index.html` | The single HTML page the app runs in |
| `vite.config.ts` | Settings for Vite, the tool that runs the dev server and builds the site |
| `tsconfig*.json`, `eslint.config.js` | TypeScript and code-style checker settings |
| `src/` | All the app's code |
| `public/models/board.glb` | The 3D skateboard model the app loads. It is generated by a script, never edited by hand |
| `assets/source/` | Design artwork the board model is built from: the deck graphic and the wheel print (SVG) |
| `scripts/` | Scripts that build the board model and check it stays within its size budget |
| `docs/` | Written documentation (see below) |
| `dist/` | The built website, created by `npm run build`. Not committed |

## Inside `src/`

| Folder | In plain terms | Key files |
| --- | --- | --- |
| `src/main.tsx` | The starting point: puts the app on the page | |
| `src/ui/` | Everything you see and click outside the 3D view | `App.tsx` lays out the page. `Presets.tsx` (trick buttons), `Inputs.tsx` (sliders), `Playback.tsx` (Pop, Pause, slow motion, timeline), `Telemetry.tsx` (results), `Objectives.tsx` (checklist), `EventLog.tsx` (history), `ViewPanel.tsx` (theme, board detail), `ShortcutsDialog.tsx` (the `?` help), `Announcer.tsx` (spoken updates for screen readers), `PerfBadge.tsx` (the `p` performance readout) |
| `src/scene/` | The 3D view | `TrickScene.tsx` sets up the 3D canvas. `Board.tsx` picks the detailed or simple board, `BoardModel.tsx` loads the detailed one, `BoardPrimitive.tsx` is the simple one. `FlightDriver.tsx` moves the board every frame. `Pad.tsx` is the ground. `SceneCamera.tsx` is the camera and mouse orbit. `SceneEnvironment.tsx` is the lighting and startup warm-up. `artDirection.ts` holds every color, light and camera number. `resources.ts` holds the shared shapes and materials |
| `src/sim/` | The physics and the trick rules. No React or 3D code, just math | `flight.ts` (how high, how long, how much it spins), `tricks.ts` (which trick it was, whether it landed, the presets and objectives), `format.ts` (turns numbers into readable text) |
| `src/store/` | The app's shared memory and the actions that change it (built with Zustand) | `index.ts` combines the pieces: `inputs.ts` (slider values), `playback.ts` (playing, paused, progress), `assessment.ts` (results, objectives, event log), `ui.ts` (theme, board detail). `export.ts` builds the downloadable JSON log |
| `src/asset/` | The math that builds the skateboard model: deck shape, trucks, wheels, textures | `spec.ts` holds every board measurement |
| `src/styles/` | The look of the page | `tokens.css` (colors, sizes, both themes), `app.css` (layout and components) |
| `src/hooks/` | Small reusable React helpers | `useReducedMotion.ts` (respects the "reduce motion" system setting) |
| `src/test/` | Test setup | `setup.ts` |

Tests sit next to the code they test, named `*.test.ts` or `*.test.tsx`.

## "I want to change..."

| Change | Where to look |
| --- | --- |
| A color, light or camera angle in the 3D view | `src/scene/artDirection.ts` |
| A color or font on the page | `src/styles/tokens.css` |
| The page layout | `src/ui/App.tsx` and `src/styles/app.css` |
| A trick name, a preset or an objective | `src/sim/tricks.ts` |
| How the board flies | `src/sim/flight.ts` |
| A slider's range | `INPUT_LIMITS` in `src/sim/tricks.ts` |
| A keyboard shortcut | `src/ui/App.tsx` and `src/ui/ShortcutsDialog.tsx` |
| The skateboard's shape or graphic | `src/asset/` or `assets/source/`, then run `npm run assets` |
| What gets logged or exported | `src/store/` |

## Commands you will use

| Command | What it does |
| --- | --- |
| `npm install` | Installs the dependencies (once, after cloning) |
| `npm run dev` | Runs the app at http://localhost:5173 while you edit (updates live) |
| `npm run build` then `npm run preview` | Builds the real website and serves it at http://localhost:4173. Use this for performance checks |
| `npm run verify` | Runs every check: types, code style, tests, board budget, then a production build and its download budget. Run it before committing |
